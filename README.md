# Cerchas Planas

Resuelve cerchas planas, calculando sus desplazamientos, reacciones y fuerzas internas de cada barra.

---

### Probar la aplicación en la nube

Haz clic en el siguiente enlace para abrir la calculadora interactiva directamente en tu navegador:

 **[Abrir Calculadora de Cerchas Planas]([https://tu-app.streamlit.app)](https://calculatorcerchasplanas-ghfpxfvnz2ceqxcj2grbsz.streamlit.app/)**

---

###  Estructura del Proyecto

* **`app.py`**: Interfaz principal que recolecta los datos, desarrollada con Streamlit.
* **`calculo.py`**: Módulo con la lógica matemática para resolver la cercha por el Metodo Matricial.
* **`resultados.py`**: Módulo encargado de la presentación visual de resultados.
* **`requirements.txt`**: Archivo con las dependencias necesarias para la ejecución.
